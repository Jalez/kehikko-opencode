- **Messages reach put-away conversations after a restart.** When Kehikot starts, every project this module keeps conversations in is picked up, so a message can wake a put-away conversation there before you open that project again. On an older Kehikot it works as before.
- **Shorter messages.** Notices from Kehikot modules and messages from other sessions now arrive with a short marker, such as ⟦Queue · report #107⟧, instead of a long frame around each one.

## For agents

- A typed message now starts with a compact marker in ⟦ ⟧ naming its sender and its id (⟦Queue · report #107⟧ for a module, ⟦Claude session · #12⟧ for a session, ⟦Your person via … · #15⟧ for the person). Your notes say once what each marker means.
