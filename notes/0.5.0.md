- **A message wakes an idle session.** When another agent session sends a message to a OpenCode session waiting at its prompt here, one line is typed into it saying who it is from, so it reads the message without you typing anything. Never while it works or waits for you, never for a message to the whole project. "Messages wake an idle session" in the module's settings turns it off.
- **Sessions can act on what other sessions ask.** With "Act on messages from other sessions" on (the default), a session takes on a request from another session in the project as if you had asked, nothing destructive or irreversible on a message's word alone, and tells you what it took on. Off: a message is only something to read.
