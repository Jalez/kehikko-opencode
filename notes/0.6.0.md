- **See what a conversation was told.** "What this conversation was told" in the View menu shows, as plain text, the notes Kehikot gave the conversation on screen: its place, the modules on its kehikko, and anything added at a prompt since.
- **Sessions learn when to use each module.** The list of modules a session is told now says, beside each one, when the module wants an agent to use it.
- **Sessions hear from modules that are not on the kehikko.** A module you installed but did not put on this kehikko can tell the session what to do without it, such as not running heavy test runs in the shell.
