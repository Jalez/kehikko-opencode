- **Queued test runs are no longer cut off after two minutes.** When Queue takes a heavy command (a test suite, a build, a typecheck), OpenCode gets the run's place in line back at once and carries on; the run is no longer cancelled by the shell's time limit, and its result is typed into the session when it finishes.

## For agents
- A heavy command Queue's guard takes returns at once with "Queued as <id>"; you'll be notified here when it finishes. Read its output with `queue_wait` or `queue_status` and the id; do not run it again.
