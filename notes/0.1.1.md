- **Installing Codex from the module no longer needs admin rights.** It uses Homebrew when you have it and otherwise installs into your home folder, so it no longer fails on a Mac where npm cannot write to `/usr/local`.
- **A failed install says what happened.** You get a plain sentence with the next step to take, and the full output stays behind "See the log".
- **Codex is found right after it installs.** Wherever the install put it, the session opens without restarting the module.
