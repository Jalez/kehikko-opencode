Kind: feature

- **Conversations started outside Kehikot can now send and receive messages.** After you type /kehikot-here in one, it is given a key and can use send_message and read_messages on the Kehikot door like any conversation started from an OpenCode container.
- **Messages reach waiting conversations faster.** Kehikot now tells this module when a message arrives, so an idle conversation is woken at once instead of at the next check.
- **A conversation that cannot message is told why.** The older send_message and read_messages tools are always listed, say what to type to place the conversation, and point to the Kehikot door where messaging now lives.
