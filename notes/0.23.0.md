- **Running conversations hear what changed.** When Kehikot or a module on the conversation's kehikko is updated, a conversation that was already running is told at its next prompt what changed for agents, once, so it does not keep using old tools or rules. You no longer have to tell it yourself.

## For agents

- After an update, your next prompt says once what changed for agents in Kehikot and in the modules on your kehikko, taken from their release notes. A subagent you start before that prompt is told the same lines.
