Kind: feature

- **Edits outside a worktree are refused** while Worktrees is on the kehikko: OpenCode's file edits, writes and patches in a project's main checkout, or in an installed module's folder, are stopped with how to make a worktree instead. Every command and file edit now goes through one shared guard check, so a new kind of guard a module declares is held here too.

## For agents

- `edit`, `write`, `multiedit` and `patch` go through the same guard check as `bash`. When a module refuses an edit (for example Worktrees, a file in a main checkout), make a worktree as its reason says and edit there.
