- **Skills you can pick from the `$` menu.** `$kehikot-here` and the skills of the modules on your kehikko now show in Codex's `$` menu and run when you type them. Before, Codex only listed them as text.
- **The same skills as Claude.** A skill that needs other modules on the kehikko is there only in a Codex conversation on a kehikko that has them. When Kehikot's Settings keep every module's skills installed, Codex has them too, Kehikot's own among them.
- **Your own skills are safe.** Kehikot puts its skills in the folder Codex reads your skills from, and only ever changes the ones it put there. A skill of yours with the same name is never replaced, and a copy you edited is left as you made it.
