- **Skills you write for a kehikko.** OpenCode sessions started on a kehikko load the skills you wrote for it in Kehikot, whatever epic they work on, and their notes list them.
- **Told when you change one.** A running session hears at its next prompt that you added, changed or removed one of the kehikko's skills, and can read the new text right away.
- **No skill claimed that is not there.** A session's notes now say which skills of the modules around it it does not have loaded, instead of listing them as if it did.

## For agents

- Skills the person wrote for this kehikko load into new sessions and are listed in the notes; one added while you run is read with `kehikko_skills` on the kehikko door.
