Kind: feature

- **Heavy-work advice follows the work queue you have installed.** When Kehikot restarts, or does not answer before a command runs, OpenCode is told how to hand tests and builds to whichever work queue module is installed, in that module's own words. With none installed, it is not told about a queue at all.

## For agents

- After a restart, or when a command ran without the guards, the note names the installed work queue and the exact shell line it gives for heavy work; if no work queue is installed the note says nothing about one.
