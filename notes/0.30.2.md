Kind: fix

- **Sessions always reconnect to Kehikot.** Every connection a OpenCode session is given now goes through the Kehikot that started this module, at an address that stays the same when a module restarts, instead of a module's own port, which can change.
- **Test copies keep to themselves.** Another Kehikot running on the same computer is never asked for a session's connections, so a test copy can no longer hand your sessions addresses that disappear with it.
