Kind: feature

- **Adopting a merge or pull request brings its OpenCode conversation along.** When you adopt a change that belongs to no epic, Kehikot can ask this module which of the project's OpenCode conversations worked on it and list them for you: ones that mention the change, its address or its branch first, then the others that ran in the repository. Choosing one files it under the place you adopt into, just as /kehikot-here does, and it is never taken from a place it already belongs to; Undo puts it back. A running conversation is not restarted.
- **Kehikot can start an OpenCode conversation for a task.** It starts with Kehikot's brief as its first prompt, is filed under the place like any conversation started here, and can be shown on its own in a Kehikot dialog while it runs.
- Needs a Kehikot that speaks protocol 2.88.0.
